# Linux Scripts — Fall 2026

A shared collection of shell scripts written by our Intro to Linux class.

## How to contribute

1. Open the `scripts/` folder and click **Add file → Create new file**.
2. Name your file `<your-github-username>.sh`.
3. Start it with `#!/bin/bash` and a comment saying what it does.
4. Commit, then open a pull request.
5. Wait for the ShellCheck check. Fix any red X before review.
